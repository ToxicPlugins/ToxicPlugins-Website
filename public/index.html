04 / GOOD TO KNOW

THE FAQ.

Everything you should know before the first public launch.

Can I download these plugins today?+

DiamondFarm is free: its product page checks for the official v2.0.0 JAR on GitHub. SkullFactory is not available for purchase yet.

What Minecraft versions are supported?+

The first stable builds have been tested on Paper 26.2 build 123 with Java 25. Support for other versions has not yet been verified or announced.

Will the plugins be free or paid?+

ToxicPlugins will offer free and paid plugins. ToxicDiamondFarm will be free (€0); ToxicSkullFactory will be premium (€1.99). This preview does not take orders or payments.

Is this for Bedrock or other games?+

No. ToxicPlugins focuses exclusively on Minecraft Java Paper server plugins.
