01 / GETTING STARTED

INSTALL WITH
CONFIDENCE.

The following steps are general Paper installation guidance. Exact commands, permissions and config keys are not published yet.

01 /

CHECK YOUR SERVER

Use a Minecraft Java Paper server. Both plugins were tested on Paper 26.2 build 123 with Java 25; other versions still need verification.

02 /

INSTALL THE JAR

Once a public release is available, stop your server, put the official plugin JAR in the plugins/ folder, and start the server.

03 /

VERIFY THE LOAD

Check the startup console for errors. In-game, run /plugins to check whether the plugin appears. Test gameplay on a separate server first.

TOXICDIAMONDFARM

A craftable, upgradeable diamond generator designed for Minecraft survival.

FREE RELEASE PENDING

WHAT THE BUILD DOES

  • Craft a diamond generator; recipe is visible in the recipe book.
  • Upgrade it through four levels using the right-click GUI.

03 / QUICK ANSWERS

GOOD TO
KNOW.

Where do I get the download?+

DiamondFarm v2.0.0 is free. Its product page checks GitHub Releases for the official JAR automatically. SkullFactory remains a premium preview at €1.99 without checkout.

Can I use Spigot, Purpur or an older Paper version?+

Compatibility has not been verified for those platforms or older versions. We only claim testing on Paper 26.2 build 123 and Java 25.

What if /plugins shows red or the plugin fails to load?+

Check your startup console, Java and Paper versions, and whether you copied the correct JAR. Avoid hot reloads during troubleshooting. Use the support page to prepare a reproducible report with relevant log lines (without passwords or IP addresses).

Where are the commands and permissions?+

Commands, permission nodes and configurable keys will be documented from the final public builds. We will not publish unverified commands or placeholders as real documentation.
